 # custom_care_management

![User](src/main/resources/pngtree-vector-valid-user-icon-png-image_516298.jpg)

## Описание
Связка микросервисов по заказу продуктов, калькуляции скидок, уведомлению покупателя
Состоит из микросервисов:
1. OrderService
2. DiscountService
3. NotificationService
4. ServerRegistry
